# 💻 Clash For Windows 使用教程

{% hint style="success" %}
Clash 是一个使用 Go 语言编写，基于规则的跨平台代理软件核心程序。

该客户端仅支持Windows 10 以上系统
{% endhint %}

{% hint style="danger" %}
安装客户端前 请先 <mark style="color:red;">**关闭杀毒软件**</mark> 再安装。以免安装不完全导致无法正常使用。下载
{% endhint %}
