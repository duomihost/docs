# 💻 Paxora For Windows 定制客户端使用教程

### 1. 系统要求

* 支持 **Windows 10 及以上版本**

### 2. Paxora 客户端下载（新客户端）

{% hint style="danger" %}
安装前请务必 **关闭杀毒软件与安全软件**，避免冲突或安装不完整
{% endhint %}

{% hint style="success" %}
* [网盘下载](https://vault.digitalage.services/index.php/s/E8srJpTGLgQNzW7) ( 网盘免登录，可直接下载 )
* [备用下载地址01](https://vault.paxoras.com/index.php/s/E8srJpTGLgQNzW7)
{% endhint %}

**下载.exe 的选项**

{% hint style="info" %}
&#x20;在网盘中，鼠标移动到文件上会出现下载箭头，点击即可下载。
{% endhint %}

### 3. 安装说明

* 双击安装包进行安装
* 安装完成后，打开软件

{% hint style="warning" %}
&#x20;若未显示，请关闭杀毒软件后重新安装。
{% endhint %}

### 4. 登录界面

1. 打开客户端，输入您在 **（Nervix）注册的邮箱与密码**进行登录。
2. 登录成功后，点击切换可以跳转选择节点界面。

### 5.选择节点

* 登录成功后，点击 **切换** 进入节点选择界面
* 根据自身需求，手动选择合适的节点

### 6. 连接享受

1. 点击 **连接按钮**
2. 等待连接成功提示

### 7. 测试连接

连接后，可以打开 [www.youtube.com](http://www.youtube.com/) 测试一下，如果油管可以打开就说明已经成功
