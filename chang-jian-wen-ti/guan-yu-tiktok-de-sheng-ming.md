# ⚙️ 关于 TikTok 的声明

我们理解部分用户希望通过节点访问 **TikTok** 内容，但需要特别说明：

* 我们的节点服务 **并非专为 TikTok 优化设计**
* 访问过程中可能出现 **不稳定、加载失败、黑屏** 等情况
* 由于 TikTok 平台地区限制较多，**无法保证访问效果，也不提供技术支持**

***

### 📌 使用建议（仅供参考）

根据部分用户反馈，以下方法或许有所帮助：

* 移动设备：尝试 **移除 SIM 卡**（iPad 通常不受影响）
* 优先选择标注为 **「家宽/住宅」** 类型的节点
* 若使用非家宽节点：
  * 将设备 **语言、地区、时间** 设置为目标国家
  * 并启用 **全局代理模式**
* 电脑端：直接访问 [https://www.tiktok.com](https://www.tiktok.com)，可在网页端浏览内容

{% hint style="danger" %}
以上建议仅供参考，效果因地区/设备差异而不同，不作为正式支持方案。
{% endhint %}
