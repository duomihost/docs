# ⚙️  流量异常

{% hint style="info" %}
说明：流量统计为自动化数据，无法人工逐条核对。
{% endhint %}

**先做这 5 步：**

1. 关高流量进程：自动更新 / 网盘同步 / P2P。
2. 查配置：防火墙/端口转发/系统代理是否把流量导向他处。
3. 查安全：异常登录、可疑脚本、陌生代理进程。
4. 控制台看「流量明细」：定位异常时段与来源。
5. 特殊环境：Docker/虚拟机/容器可能单独消耗流量。

{% hint style="success" %}
**仍异常？请提交：** 异常时间段 + 设备/客户端 + 流量明细截图（便于复核）。
{% endhint %}
