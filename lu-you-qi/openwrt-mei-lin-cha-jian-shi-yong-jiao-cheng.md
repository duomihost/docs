# OpenWrt / 梅林插件安装包选择与安装教程

本教程用于帮助 **OpenWrt** 以及 **梅林 / 官改 / 梅改** 用户选择正确的插件安装包。

不同固件使用的安装包格式不同，请先确认自己的路由器固件类型，再下载对应版本。

> **注意**
>
> `.ipk`、`.apk` 和 `.tar.gz` 都是插件安装包，不是路由器系统固件。\
> 请勿上传到路由器的“固件升级”页面。

***

### 1. 安装包怎么选

{% hint style="success" %}
* [网盘下载](https://vault.digitalage.services/index.php/s/bk5ycyBXp6wDYYB)&#x20;
{% endhint %}

先确认自己的路由器使用什么固件。

| 路由器固件           | 安装包                     | 说明             |
| --------------- | ----------------------- | -------------- |
| 旧版 OpenWrt      | `.ipk`                  | 使用 IPK 软件包     |
| 新版 OpenWrt      | `.apk`                  | 使用 APK 软件包     |
| 梅林 / 官改 / 梅改    | `.tar.gz`               | 需要根据机型选择对应架构   |
| OpenWrt Full 版本 | `full.ipk` / `full.apk` | 通用版本，自动识别路由器架构 |

简单来说：

* **旧版 OpenWrt** → 下载 `.ipk`
* **新版 OpenWrt** → 下载 `.apk`
* **不知道 OpenWrt 路由器架构** → 下载带 `full` 的版本
* **梅林 / 官改 / 梅改** → 下载对应架构的 `.tar.gz`

### 2. OpenWrt 安装包选择

#### 2.1 IPK 和 APK 有什么区别？

OpenWrt 新旧版本使用的软件包格式不同。

旧版 OpenWrt 使用：

```
.ipk
```

新版 OpenWrt 使用：

```
.apk
```

因此下载插件时，需要根据自己的 OpenWrt 版本选择对应的软件包。

> **提示**
>
> IPK 和 APK 只是软件包格式不同，与路由器 CPU 架构不是一回事。

如果不确定自己的固件使用 IPK 还是 APK，可以 SSH 登录路由器后执行：

```
command -v opkg
command -v apk
```

如果返回了 `opkg` 路径，则选择：

```
.ipk
```

如果返回了 `apk` 路径，则选择：

```
.apk
```

***

#### 2.2 Full 通用版是什么？

如果安装包文件名中带有：

```
full
```

则表示这是 **OpenWrt 通用版本**。

Full 版本会自动识别当前路由器的 CPU 架构，一般不需要用户手动判断自己的设备是：

```
x86_64
aarch64
arm
mips
mipsel
```

或其他架构。

例如下载页面中有：

```
xxx-full.ipk
```

表示：

**旧版 OpenWrt IPK 通用版**

如果有：

```
xxx-full.apk
```

表示：

**新版 OpenWrt APK 通用版**

如果你不知道自己的 OpenWrt 是什么架构，建议优先下载对应格式的 **Full 通用版**。

> **注意**
>
> `full` 只能自动识别路由器架构。
>
> 它不能自动判断应该使用 IPK 还是 APK。
>
> 所以仍然需要先确认：
>
> ```
> 旧版 OpenWrt → full.ipk
> 新版 OpenWrt → full.apk
> ```

***

#### 2.3 OpenWrt 应该下载哪个？

可以按照下面的方法选择。

**旧版 OpenWrt**

下载：

```
xxx.ipk
```

如果不知道自己的 CPU 架构，下载：

```
xxx-full.ipk
```

**新版 OpenWrt**

下载：

```
xxx.apk
```

如果不知道自己的 CPU 架构，下载：

```
xxx-full.apk
```

### 3. OpenWrt 安装方法

下载正确的安装包以后，进入 OpenWrt 管理后台。

一般可以在：

**系统 → 软件包**

找到本地软件包安装功能。

不同 OpenWrt 固件或主题的按钮名称可能不同，例如：

* 上传软件包
* 安装本地软件包
* 手动安装
* 上传并安装

选择刚才下载的 `.ipk` 或 `.apk` 文件，然后安装即可。

安装完成后刷新路由器后台页面。

如果插件菜单没有立即出现，可以尝试：

1. 刷新浏览器页面
2. 退出后台重新登录
3. 清除浏览器缓存
4. 确认安装日志没有报错
5. 重启路由器

***

#### 3.1 SSH 安装 IPK

如果已经把 IPK 文件上传到了路由器 `/tmp` 目录，可以执行：

```
opkg install /tmp/插件文件名.ipk
```

例如：

```
opkg install /tmp/xxx-full.ipk
```

***

#### 3.2 SSH 安装 APK

新版 OpenWrt 可以使用：

```
apk add /tmp/插件文件名.apk
```

例如：

```
apk add /tmp/xxx-full.apk
```

如果本地安装包因为签名问题无法安装，请以插件发布页面提供的安装命令为准。

***

### 4. 梅林 / 官改 / 梅改安装包选择

梅林、官改以及梅改固件使用：

```
.tar.gz
```

格式的安装包。

> **注意**
>
> 正确后缀是 `.tar.gz`，不是 `.ar.gz`。

梅林版本与 OpenWrt 不同。

OpenWrt 可以使用 Full 通用版自动识别架构，而梅林通常需要根据自己的 **路由器型号和固件平台** 下载对应版本。

常见的平台包括：

```
arm
hnd
hnd_v8
qca
mtk
ipq32
ipq64
```

不要随便选择一个 `.tar.gz` 安装。

***

### 5. 怎么查看梅林路由器对应架构？

梅林 / 官改 / 梅改用户可以参考 fancyss 项目整理的支持机型列表：

[查看 fancyss 支持机型和固件架构](https://github.com/hq450/fancyss)

打开页面以后，找到自己的 **路由器完整型号**。

然后查看该机型对应的平台或 fancyss 版本。

常见对应关系如下：

| fancyss 版本       | 对应平台     |
| ---------------- | -------- |
| `fancyss_arm`    | `arm`    |
| `fancyss_hnd`    | `hnd`    |
| `fancyss_hnd_v8` | `hnd_v8` |
| `fancyss_qca`    | `qca`    |
| `fancyss_mtk`    | `mtk`    |
| `fancyss_ipq32`  | `ipq32`  |
| `fancyss_ipq64`  | `ipq64`  |

例如，在 fancyss 支持列表中找到自己的路由器后，如果对应版本显示：

```
fancyss_hnd_v8
```

那么在本插件下载页面中，就应该选择：

```
hnd_v8
```

对应的 `.tar.gz` 安装包。

例如：

```
xxx-hnd_v8.tar.gz
```

> **重要**
>
> 不建议只根据 `ARM`、`ARM64` 或 CPU 型号猜梅林安装包。
>
> 不同路由器即使 CPU 指令集相似，软件中心平台也可能不同。
>
> **请优先根据路由器完整型号查询对应平台。**

***

### 6. 梅林插件安装方法

下载正确的 `.tar.gz` 安装包以后，进入路由器后台。

打开：

**软件中心 → 离线安装**

部分固件中也可能显示为：

**软件中心 → 手动安装**

然后选择刚才下载的：

```
xxx.tar.gz
```

文件并上传。

等待软件中心完成安装即可。

> **注意**
>
> `.tar.gz` 文件通常不需要自己解压。
>
> 直接上传完整的 `.tar.gz` 文件即可。

安装过程中不要：

* 刷新页面
* 关闭路由器电源
* 重启路由器
* 重复点击安装按钮

安装完成后刷新软件中心，即可查看插件。

### 9. 常见问题

#### 安装时提示软件包格式错误

一般是 IPK 和 APK 选错了。

重新确认自己的 OpenWrt 使用：

```
opkg
```

还是：

```
apk
```

然后重新下载对应版本。

***

#### 提示架构不兼容

OpenWrt 用户如果不知道架构，可以直接改用 Full 通用版。

旧版 OpenWrt：

```
full.ipk
```

新版 OpenWrt：

```
full.apk
```

梅林用户则需要重新查询自己的机型对应：

```
arm
hnd
hnd_v8
qca
mtk
ipq32
ipq64
```

中的哪个平台。

***

#### Full 可以同时给新旧 OpenWrt 使用吗？

不可以。

Full 只是通用架构版本。

软件包格式仍然不同：

```
旧版 OpenWrt → full.ipk
新版 OpenWrt → full.apk
```

***

#### 梅林可以安装 IPK 或 APK 吗？

不可以。

梅林 / 官改 / 梅改请选择：

```
.tar.gz
```

安装包。

***

#### TAR.GZ 需要解压吗？

一般不需要。

直接在梅林软件中心的 **离线安装** 页面上传完整的 `.tar.gz` 文件即可。

***

#### fancyss 是本插件的下载地址吗？

不是。

fancyss 在本教程中主要用于帮助梅林用户查询：

**路由器型号 → 对应固件平台 / 插件架构**

插件本体仍然需要从本插件自己的下载页面获取。

***

#### fancyss 找不到我的路由器型号怎么办？

不要选择一个看起来相似的型号直接安装。

请确认：

* 路由器完整型号
* 当前固件名称
* 当前固件版本
* CPU / SoC 型号

然后再确认插件是否支持该设备。
