# 📱 TabNet For Android 定制客户端使用教程

### 1. 系统要求

* 支持 **Android 9 及以上版本**

{% hint style="success" %}
**本教程适用于安卓、鸿蒙系统的平板及手机设备**

* 部分设备可能存在兼容性问题，如无法使用，请尝试其他 Android 客户端
* 安装前请务必 **关闭手机的安全守护或杀毒软件**，否则可能导致无法安装
{% endhint %}

### 2. TabNet 客户端下载（新客户端）

{% hint style="danger" %}
安装客户端前 请先 <mark style="color:red;">把手机的安全守护关了</mark> 再安装。否则无法安装。
{% endhint %}

{% hint style="success" %}
* [网盘下载 ](https://wwet.lanzoup.com/iHC1z2wy2ygb)(( 网盘免登录，可直接下载 )
* [备用下载地址01](https://vault.digitalage.services/index.php/s/4s3kK72ZCdEiXDE)
{% endhint %}

### 3. 登录界面

* 打开客户端，输入您在 **熊猫云村（TabNet）注册的邮箱与密码** 登录

<figure><img src="../.gitbook/assets/888.jpg" alt="" width="188"><figcaption><p>登录界面</p></figcaption></figure>

### 4. 开始使用

{% hint style="warning" %}
**tip:** 第一次登录会拉取订阅，有点慢，请耐心等等。<mark style="color:red;">仅第一次登录会这样。</mark>
{% endhint %}

<div><figure><img src="../.gitbook/assets/777.jpg" alt="" width="188"><figcaption><p>第一次登陆时间可能会长一点请耐心等待</p></figcaption></figure> <figure><img src="../.gitbook/assets/555.jpg" alt="" width="188"><figcaption><p>拉完订阅的状态</p></figcaption></figure></div>

如果长时间未刷新出正常节点。请退出软件重新打开。

<figure><img src="../.gitbook/assets/666.jpg" alt="" width="188"><figcaption><p>退出后台，重新打开app</p></figcaption></figure>

### 5. 选择节点

* 登录成功后，根据使用需求选择节点

{% hint style="success" %}
ChatGPT（<mark style="color:red;">香港暂未支持</mark>） 请选择日本、美国、新加坡、韩国等其他国家。
{% endhint %}

### 6. 连接享受

1. 点击 **连接按钮**
2. 等待软件提示连接成功

<div><figure><img src="../.gitbook/assets/555.jpg" alt="" width="188"><figcaption><p>点击连接按钮</p></figcaption></figure> <figure><img src="../.gitbook/assets/c2fddce4-4138-4d86-9bc3-7d8df43c6f12.jpg" alt="" width="188"><figcaption><p>出现这个连接请求，一定要点确定</p></figcaption></figure></div>

### 7. 测试连接

连接后，可以打开 [www.youtube.com](http://www.youtube.com/) 测试一下，如果油管可以打开就说明已经成功
