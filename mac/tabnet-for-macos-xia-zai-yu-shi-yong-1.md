## 使用教程

### 1. 系统要求

{% hint style="success" %}
Clash 是一个使用 Go 语言编写，基于规则的跨平台代理软件核心程序。

该客户端仅支持**Mac os** 10 以上系统
{% endhint %}

### 2. 应用下载

&#x20;网盘下载

{% hint style="success" %}
[ 网盘下载01](https://tagcloud.lanzouw.com/i0adC2i5em2j)

[ 网盘下载02](https://share.feijipan.com/s/moEUHJ2p)
{% endhint %}

下载完毕后，我们按照下方图示操作完成安装

<figure><img src="../.gitbook/assets/image (40).png" alt=""><figcaption></figcaption></figure>

### 3. 首次运行

{% hint style="warning" %}
安装完成后，我们在应用程序里面找到ClashX，然后打开它，

1. 如果系统提示不安全，无法打开，我们需要打开一个开启所有来源的开关，具体看教程👉 [mac-os-kai-qi-ren-he-lai-yuan-an-zhuang-quan-xian-jiao-cheng.md](../chang-jian-wen-ti/mac-os-kai-qi-ren-he-lai-yuan-an-zhuang-quan-xian-jiao-cheng.md "mention")
2. 如果能正常打开，请继续往下阅读
{% endhint %}

1. 开启后打开程序就是这样的，如下图所示

<figure><img src="../.gitbook/assets/image (41).png" alt=""><figcaption></figcaption></figure>

2. 第一次使用，需要安装一个帮助程序，我们点击“安装”&#x20;
3. 输入您系统密码验证一下即可

{% hint style="warning" %}
如果安装不了，就是设置没开启 “任何来源” 选项， 清查阅此教程： [开启任何来源教程](https://mbd.baidu.com/newspage/data/dtlandingshare?sourceFrom=search_a\&nid=dt_4845909930472156259)
{% endhint %}

### 4. 导入订阅

首先回到 官网并登录：[hi.dmhosts.com](https://hi.dmhosts.com)

1. 复制个人订阅地址

<figure><img src="../.gitbook/assets/image (53).png" alt=""><figcaption></figcaption></figure>

2. 我们打开 Clash Verge，点击订阅，粘贴已复制的订阅并导入

<figure><img src="../.gitbook/assets/image (43).png" alt=""><figcaption></figcaption></figure>

{% hint style="danger" %}
如果下载配置文件出现 **`Network Error`**：

1. 请回到官网刷新页面后重新复制地址（网站提供 3 个可用地址）
2. 或更换网络环境（例如使用手机 4G/5G 热点）
{% endhint %}

3. 点击代理，节点出来后，我们在手动选一个。

<figure><img src="../.gitbook/assets/image (44).png" alt=""><figcaption></figcaption></figure>

4. 点击设置，开启“系统代理”即可。

<figure><img src="../.gitbook/assets/image (45).png" alt=""><figcaption></figcaption></figure>

连接后，可以打开 [www.youtube.com](http://www.youtube.com/) 测试一下，如果油管可以打开就说明已经成功

{% hint style="success" %}

{% endhint %}

1. 确保当前处于 **未连接状态**

<figure><img src="../.gitbook/assets/image (46).png" alt="" width="375"><figcaption></figcaption></figure>

{% hint style="danger" %}

2. 找到需要更新的配置文件，点击托管配置，点击更新

{% hint style="danger" %}

## 开启全局代理模式（GLOBAL）

1. 在代理页面。
2. 在右上角选**GLOBAL（全局）。**
3. 重新选一个节点。
4. 去设置，重新打开系统代理

### 使用建议

* 建议日常使用 **规则模式**，在需要时切换至 **全局模式**
* 如果全局模式下访问国内网站速度较慢，可以临时切回分流模式
* 切换模式后如遇异常，尝试重新连接或更新订阅
